# bmxueel

Portfolio site for BM Alimuzzaman, social media manager and video editor.

Plain HTML, CSS and JS with no build step and no dependencies. It's hosted on Vercel.

## Run locally

```bash
npm run dev
```

Then open http://localhost:5173. You need Node.js but not `npm install`.

## Editing

- **Videos:** edit the `VIDEOS` list at the top of `script.js`. Paste any YouTube link and set a title.
- **Text:** edit `index.html`.
- **Colors and spacing:** use the tokens at the top of `styles.css`.

Push to `main` and Vercel redeploys automatically.
